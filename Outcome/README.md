# Outcome

This folder has videos and pictures of GPT On Wheels at work, and it has the AI's thoughts and terminal output.

## Guide

There are 4 subdirectories:
  - Autonomous (runs from autonomous.py)
  - Watching (runs from watch.py)
  - Interpret (runs from interpret.py)
  - Turns (from test_turning.py in Electronics,Sensors,Motors)
  - Extra Runs (for extra footage of GPT On Wheels)
I have more videos and image of GPT On Wheels but these are the main ones so they are in Outcome.

Autonmous, watching, and interpret are grouped into each individual run and each have the main AI log and some have the full output
(I did not include the full output for all runs because it just includes camera data print statements and is unnceccessary when it gets extremely long in long runs).
