\# Interpret



\*\*The AI can interpret signs that tell it what to do and do accordingly. Ex: if it says forward, it would go forward. It worked fine some weeks ago, but now it is not working because the high-end llm it requires is not available.\*\*



\## Not-Free Problem



Interpet's code works just fine, but the reason why interpret is not working is because both Ollama and Openrouter don't offer what interpret needs. Interpret needs tool-calling llms but these are high-end and expensive. Ollama allows these but they are so expansive that they take too much space, so getting them on a computer would be impossible. Openrouter used to allow these (thats how I got it working first) but now they don't. This has 3 reasons:



1. \*Free Credit\* - Before sometimes I would use free temporary credit from my new account
2. \*Demand\* - If an llm is popular, openrouter will restrict non-paying users access to it
3. \*Token Price\* - Tecnically there are free tool llms but 99% of good tool-calling is paid
4. \*Rate Limit\* - Openrotuer automatically limits after some time.



These are the reasons that Openrotuer gives me "No Matching Endpoints". There are some more reasons like high privacy settings (which disable free models you need to disable privacy to use free models).



This is something I don't have control over and it was working some weeks ago but is not now. But, this is an issue with the providers not the code.
